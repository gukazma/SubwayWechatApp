# 地铁支援系统 - 完整流程测试计划

## 测试环境
- 前端地址: http://localhost:5173
- 后端地址: http://localhost:3000
- 测试平台: H5 (浏览器) / 微信开发者工具

## 测试流程

### 1. 登录流程测试

#### 1.1 首次登录
- [ ] 打开应用，跳转到登录页面
- [ ] 点击"微信授权登录"按钮
- [ ] 显示"登录中..."加载状态
- [ ] 登录成功后显示"登录成功"提示
- [ ] 自动跳转到首页（站点列表）

#### 1.2 自动登录
- [ ] 刷新页面
- [ ] 自动恢复登录状态
- [ ] 直接进入首页，无需重新登录

### 2. 站点列表测试

#### 2.1 加载站点列表
- [ ] 进入首页，显示加载动画
- [ ] 成功加载5个站点（人民广场站、南京东路站、陆家嘴站、世纪大道站、静安寺站）
- [ ] 每个站点显示站点名称、线路、出入口数量

#### 2.2 点击站点
- [ ] 点击任意站点卡片
- [ ] 跳转到站点详情页面

#### 2.3 错误处理
- [ ] 停止后端服务，刷新页面
- [ ] 显示错误提示"网络错误，请检查连接后重试"
- [ ] 显示"重新加载"按钮
- [ ] 点击"重新加载"按钮，重新请求数据

### 3. 站点详情测试

#### 3.1 加载站点详情
- [ ] 进入站点详情页面，显示加载动画
- [ ] 显示站点名称和线路
- [ ] 显示该站点的所有出入口
- [ ] 每个出入口显示名称、当前人数、需要人数、状态

#### 3.2 状态显示
- [ ] 红色状态：人员紧缺（short）
- [ ] 黄色状态：人员正常（normal）
- [ ] 绿色状态：人员充足（full）

#### 3.3 点击出入口
- [ ] 点击任意出入口卡片
- [ ] 跳转到出入口详情页面

### 4. 出入口详情测试

#### 4.1 显示出入口信息
- [ ] 显示出入口名称
- [ ] 显示所属站点名称
- [ ] 显示当前状态（人员紧缺/正常/充足）

#### 4.2 报名按钮
- [ ] 状态为"人员紧缺"或"人员正常"时，显示"立即报名支援"按钮
- [ ] 状态为"人员充足"时，按钮显示"人员充足，暂不需要支援"且不可点击

#### 4.3 点击报名
- [ ] 点击"立即报名支援"按钮
- [ ] 跳转到报名确认页面

### 5. 报名流程测试

#### 5.1 表单验证
- [ ] 不填写任何信息，点击"确认报名"按钮
- [ ] 显示提示"请填写完整信息"
- [ ] 按钮保持禁用状态

#### 5.2 日期选择
- [ ] 点击日期选择器
- [ ] 选择未来30天内的日期
- [ ] 日期显示在选择器中

#### 5.3 时间选择
- [ ] 选择开始时间和结束时间
- [ ] 结束时间早于开始时间时，显示提示"结束时间必须大于开始时间"

#### 5.4 提交报名
- [ ] 填写完整信息后，按钮变为可点击状态
- [ ] 点击"确认报名"按钮
- [ ] 显示"提交中..."状态
- [ ] 报名成功后显示"报名成功"提示
- [ ] 自动跳转到"我的支援记录"页面

### 6. 我的支援记录测试

#### 6.1 加载记录列表
- [ ] 进入"我的支援记录"页面
- [ ] 显示所有报名记录
- [ ] 每条记录显示：站点名称、出入口名称、日期、时间、状态

#### 6.2 状态显示
- [ ] 待确认（pending）：黄色状态
- [ ] 已确认（confirmed）：蓝色状态
- [ ] 已完成（completed）：绿色状态
- [ ] 已取消（cancelled）：灰色状态

#### 6.3 取消报名
- [ ] 找到状态为"待确认"的记录
- [ ] 点击"取消报名"按钮
- [ ] 显示确认弹窗"确定要取消这次支援报名吗？"
- [ ] 点击"确定"按钮
- [ ] 显示"已取消报名"提示
- [ ] 记录状态变为"已取消"

#### 6.4 空状态
- [ ] 取消所有记录后
- [ ] 显示空状态提示"暂无支援记录"

### 7. 个人信息测试

#### 7.1 查看个人信息
- [ ] 进入"我的"页面
- [ ] 显示用户头像、昵称
- [ ] 点击"个人信息"菜单项
- [ ] 显示用户ID、昵称、注册时间

#### 7.2 退出登录
- [ ] 点击"退出登录"按钮
- [ ] 显示确认弹窗"确定要退出登录吗？"
- [ ] 点击"确定"按钮
- [ ] 显示"已退出登录"提示
- [ ] 自动跳转到登录页面

#### 7.3 重新登录
- [ ] 退出登录后，再次点击"微信授权登录"
- [ ] 成功登录后进入首页

### 8. 完整流程测试

#### 8.1 完整报名流程
- [ ] 登录 → 选择站点 → 选择出入口 → 填写信息 → 提交报名
- [ ] 查看我的支援记录，确认记录已创建
- [ ] 取消报名，确认状态已更新

#### 8.2 多次报名
- [ ] 报名多个不同的出入口
- [ ] 在"我的支援记录"中查看所有记录

### 9. 异常情况测试

#### 9.1 网络异常
- [ ] 断开网络连接
- [ ] 尝试加载数据
- [ ] 显示网络错误提示
- [ ] 恢复网络后，点击"重新加载"按钮
- [ ] 数据正常加载

#### 9.2 Token过期
- [ ] 清除本地存储的token
- [ ] 刷新页面
- [ ] 显示"登录已过期，请重新登录"提示
- [ ] 自动跳转到登录页面

#### 9.3 参数错误
- [ ] 直接访问不存在的页面
- [ ] 显示错误提示
- [ ] 返回上一页
